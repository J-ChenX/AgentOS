# 前端架构说明

`web/src/` 是 AgentOS 的 React + TypeScript 单页应用，使用 Vite 构建，产物输出到 `src/agentos/_web_assets/`。开发模式在 `http://localhost:6493` 独立运行。

## Adapter 模式

所有数据操作通过 `AgentAdapter` 实例进行，**组件不直接调用 `fetch()`**。这使所有组件可以用 `MockAdapter` 独立测试。

### AgentAdapter 接口（types/index.ts）

```typescript
interface AgentAdapter {
  runAgent(params: { task: string; agentId?: string }): AsyncIterable<StreamEvent>;
  cancelTask(taskId: string): Promise<void>;
  submitComponentAction(actionId: string, payload: unknown): Promise<void>;
  getHistory(): Promise<TaskRecord[]>;
  getTaskDetail(taskId: string): Promise<TaskRecord>;
  getSkills(): Promise<Skill[]>;
  toggleSkill(name: string, enabled: boolean): Promise<void>;
  listFiles(path?: string): Promise<FileNode[]>;
  getConfig(): Promise<AgentConfig>;
  updateConfig(patch: Partial<AgentConfig>): Promise<void>;
}
```

### Adapter 切换

| 模式 | 类 | 使用场景 |
|------|-----|---------|
| `mock`（默认）| `MockAdapter` | 本地 UI 开发、CI 测试 |
| `web` | `WebAdapter` | 连接运行中的 `agentos run` 后端 |

运行时切换：URL 追加 `?adapter=web`。

### WebAdapter（adapter/web.ts）

真实客户端。关键实现：
- 两步任务生命周期：`POST /api/tasks` → `GET /api/tasks/{id}/stream`
- SSE 断线自动重连（最多 5 次，指数退避）
- 重连时发送 `Last-Event-ID` 头，支持丢失事件回放
- 收到终止事件（`done`、`error`、`cancelled`）后停止重连

### MockAdapter（adapter/mock.ts）

确定性假数据，用于开发和测试：
- `runAgent()` 返回带模拟延迟的固定事件序列
- 特殊前缀：`"error: ..."` 触发错误事件，`"cancel: ..."` 触发取消事件
- 其他方法返回硬编码内存数据

## StreamEvent 类型（types/index.ts）

`StreamEvent` 联合类型覆盖后端所有可能的事件，discriminant 字段为 `type`：

```typescript
type StreamEvent =
  | TaskStartedEvent      // { type: 'task_started', task_id, seq }
  | ThinkingEvent         // { type: 'thinking', content, seq }
  | SkillCallEvent        // { type: 'skill_call', id, skill, args, status, seq }
  | SkillResultEvent      // { type: 'skill_result', id, skill, status, result?, error?, seq }
  | TextEvent             // { type: 'text', content, seq }
  | ComponentEvent        // { type: 'component', id, component_type, data, seq }
  | ComponentDeltaEvent   // { type: 'component_delta', id, op, path, value, seq }
  | ActionRequiredEvent   // { type: 'action_required', action_id, component_type, data, blocking, seq }
  | ErrorEvent            // { type: 'error', level, message, task_id, recoverable, seq }
  | DoneEvent             // { type: 'done', task_id, summary, seq }
  | CancelledEvent        // { type: 'cancelled', task_id, seq }
```

### component_delta 操作类型

| `op` | 效果 |
|------|------|
| `append` | 将 `value` 追加到 `path` 指向的数组 |
| `set` | 设置 `path` 指向的值 |
| `merge` | 将 `value`（对象）浅合并到 `path` 指向的对象 |
| `replace` | 替换整个 `data` 对象 |

## 状态管理 — useEventReducer

`ChatState` 是当前对话的单一状态源：

```typescript
interface ChatState {
  taskId: string | null;
  status: TaskStatus | 'idle';
  events: StreamEvent[];                         // 完整有序事件历史
  components: Record<string, ComponentState>;    // 实时组件状态（按 id）
  pendingAction: StreamEvent | null;
}
```

Reducer 处理两个 action：
- `{ type: 'RESET' }` — 新任务开始前清空状态
- `{ type: 'PUSH_EVENT'; event: StreamEvent }` — 追加事件，更新派生状态

内部用 `immer` 的 `produce` 实现符合人体工程学的不可变更新。

### 组件中使用

```typescript
const [state, dispatch] = useReducer(chatReducer, initialChatState);

dispatch({ type: 'RESET' });
for await (const event of adapter.runAgent({ task: prompt })) {
  dispatch({ type: 'PUSH_EVENT', event });
}
```

## 布局系统 — useLayoutPersistence

布局是持久化到 `localStorage`（key: `'agentos-layout-v2'`）的递归 `ViewportNode` 树：

```typescript
interface ViewportNode {
  id: string;
  type?: ViewportType;               // 叶节点：渲染哪个面板
  split?: 'horizontal' | 'vertical'; // 分支节点：分割方向
  sizes?: number[];                   // 分支节点：百分比宽/高
  children?: ViewportNode[];          // 分支节点：子节点
}
```

叶节点有 `type`，分支节点有 `split`、`sizes`、`children`。根节点默认为垂直分割：`files`（25%）和 `chat`（75%）。

### 布局操作

```typescript
const { layout, updateViewportType, splitViewport, closeViewport } = useLayoutPersistence();

updateViewportType(nodeId, 'config');    // 更改面板类型
splitViewport(nodeId, 'vertical');       // 分割为两栏
closeViewport(nodeId);                   // 关闭，兄弟节点接替父节点位置
```

### allotment 方向说明

注意 allotment 库的方向与直觉相反：
- `split: 'horizontal'`（水平分割线）→ `<Allotment vertical={true}>`
- `split: 'vertical'`（垂直分割线）→ `<Allotment vertical={false}>`

## EventRenderer

按 `event.type` 路由到对应组件：

| 事件类型 | 渲染组件 |
|---------|---------|
| `thinking` | `<ThinkingBubble>` |
| `text` | `<TextBlock>` |
| `skill_call` / `skill_result` | `<SkillCallCard>` |
| `component` | `<DynamicComponent component={components[event.id]}>` |
| `action_required` | `<DynamicComponent ... onAction={adapter.submitComponentAction}>` |
| `error` | `<ErrorCard>` |
| `done` | `<DoneCard>` |
| `cancelled` | `<CancelledCard>` |
| `task_started` / `component_delta` | `null`（无视觉输出）|

## 样式规范 — Tailwind v4

主题在 `styles/index.css` 的 `@theme` 块中定义 CSS 自定义属性：

```css
@theme {
  --color-bg-primary: #1e1e2e;
  --color-bg-secondary: #282840;
  --color-accent: #7c6ff7;
  --color-text-primary: #e0e0e8;
  /* ... */
}
```

**规范**：
- 语义颜色 token → `style={{ color: 'var(--color-text-primary)' }}`
- 间距、尺寸、布局 → Tailwind 工具类（`p-4`、`flex`、`gap-2`、`text-sm`）
- 不要将颜色硬编码在组件中，统一从 CSS 变量读取

## 新增面板类型规范

### 步骤 1：创建面板组件

```typescript
// web/src/components/panels/MyPanel.tsx
import type { AgentAdapter } from '../../types';

export default function MyPanel({ adapter }: { adapter: AgentAdapter }) {
  // 只用 adapter 获取数据，不直接 fetch
}
```

### 步骤 2：添加类型到布局系统

```typescript
// web/src/types/layout.ts
export type ViewportType = 'chat' | 'files' | ... | 'my-panel' | `plugin:${string}`;

export const VIEWPORT_LABELS: Record<string, string> = {
  ...
  'my-panel': '我的面板',
};
```

在 `ViewportContainer.tsx` 的 `BUILTIN_TYPES` 中添加 `'my-panel'`，使其出现在类型选择器中。

### 步骤 3：在 WidgetRegistry 注册

```typescript
// web/src/components/layout/WidgetRegistry.tsx
import MyPanel from '../panels/MyPanel';
const REGISTRY = { ..., 'my-panel': MyPanel };
```

### 步骤 4：如需新数据，扩展 AgentAdapter

```typescript
// types/index.ts — 接口中添加方法
myNewData(): Promise<MyType[]>;

// adapter/mock.ts
async myNewData() { return []; }

// adapter/web.ts
async myNewData() { return this.request('/api/my-data'); }
```

### TypeScript strict 模式注意事项

所有 component 事件的 `data` 字段类型为 `Record<string, unknown>`，访问具体属性时需显式转换：

```typescript
(data.columns as string[]) || []
data.title as string
```
