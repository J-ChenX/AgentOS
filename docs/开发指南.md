# AgentOS 开发指南

## 环境搭建

### 安装

```bash
# 安装框架（开发模式）
pip install -e ".[dev]"

# 安装前端依赖
cd web && pnpm install   # 推荐；npm install 也可以
```

### 开发服务器

开两个终端：

```bash
# Terminal 1 — 前端 HMR，访问 http://localhost:6493
cd web && pnpm dev

# Terminal 2 — 后端 hot-reload
agentos run --dev --port 8000
```

前端通过 `?adapter=web` 参数连接真实后端，默认使用 MockAdapter。

### 试用示例项目

```bash
cd examples/data_analysis
agentos run
# 浏览器访问 http://localhost:8000
```

## 环境变量（`.env`，不提交 VCS）

| 变量 | 用途 |
|------|------|
| `OPENAI_API_KEY` | OpenAI 模型 |
| `ANTHROPIC_API_KEY` | Anthropic 模型 |
| `GEMINI_API_KEY` | Google Gemini |
| `TAVILY_API_KEY` | web_search Skill |
| 任意厂商 key | LiteLLM 按 model 名前缀路由 |

`LLM_BASE_URL` 不是密钥，可写在 `agent.toml` 中。

## 代码规范

- Python 3.11+，`from __future__ import annotations`
- 行长 99 字符（ruff）
- 双引号字符串
- 所有公开函数加类型注解
- 提交前执行 `ruff check` 和 `ruff format`

## 测试

```bash
# 后端测试
python -m pytest tests/ -v

# 单个模块
python -m pytest tests/core/test_skill_loader.py -v

# 前端测试
cd web && npx vitest run

# 前端监视模式
cd web && npx vitest
```

服务端测试使用 `pytest-anyio`（`asyncio_mode = "auto"`），`tests/server/conftest.py` 提供基于 `ASGITransport` 的 `AsyncClient` fixture。

## 生产构建

```bash
# 编译前端到 src/agentos/_web_assets/
make build-web

# 打包 Python wheel（含 _web_assets）
make build

# 手动步骤
cd web && pnpm install && pnpm run build
cp -r web/dist/* src/agentos/_web_assets/
python -m build
```

`pyproject.toml` 中 `artifacts` 字段确保 `_web_assets/**` 被打包进 wheel：

```toml
[tool.hatch.build.targets.wheel]
packages = ["src/agentos"]
artifacts = ["src/agentos/_web_assets/**"]
```

## 添加 CLI 命令

1. 在 `cli/` 下新建或修改对应文件
2. 在 `src/agentos/cli/app.py` 注册：

```python
from agentos.cli.my_cmd import my_command
app.command("my-cmd")(my_command)
```

3. 在 `tests/cli/test_my_cmd.py` 用 `typer.testing.CliRunner` 编写测试
