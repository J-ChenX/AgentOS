# AgentOS 启动说明

本文档说明两种使用场景下的完整启动流程。

> 所有命令均以**仓库根目录**（含 `pyproject.toml` 的目录）为起点，使用相对路径。

---

## 模式一：开发 / 测试模式

适用于：正在开发或调试 AgentOS 框架本身，需要前端热更新（HMR）。

### 前提条件（首次使用，只需做一次）

```bash
# 1. 安装 Python 依赖（在仓库根目录）
pip install -e ".[dev]"

# 2. 安装前端依赖
cd web; pnpm install; cd ..

# 3. 设置前端默认使用真实后端（不需要每次带 URL 参数）
echo "VITE_ADAPTER=web" > web/.env.local
```

### 创建 Agent 项目（只需做一次）

在仓库根目录下执行，会自动读取当前目录的 `.env` 中的 API 配置：

```bash
agentos init my_agent
```

成功输出示例：
```
✓ 项目 'my_agent' 创建成功
  已从 .env 复制 .env
  LLM: gemini-3-pro-preview → https://ai.t8star.cn/v1
  cd my_agent
  agentos run --dev --port 8000
```

### 每次启动

**方式 A：单命令启动（推荐，在仓库根目录）**

```bash
pnpm dev
```

> 默认后端项目目录为 `my_agent`。若项目名称不同，通过环境变量指定：
> ```bash
> AGENT_DIR=../your_project pnpm dev
> ```
> 或在 `web/.env.local` 中永久设置：
> ```
> AGENT_DIR=../your_project
> ```

**方式 B：双终端分开启动（调试时使用，在仓库根目录）**

```bash
# 终端 1 —— 仅启动前端
pnpm --filter web dev
# ✓ 前端运行在 http://localhost:6493

# 终端 2 —— 启动后端（在 Agent 项目目录）
cd my_agent
agentos run --dev --port 8000
# ✓ 后端运行在 http://localhost:8000
```

### 打开浏览器

```
http://localhost:6493
```

> 已通过 `web/.env.local` 设置 `VITE_ADAPTER=web`，前端会自动连接后端，无需附加 URL 参数。

## 模式二：生产 / 用户模式

适用于：普通用户安装使用，或将框架打包分发。前端静态资源内嵌在包中，单终端单命令启动。

### 发布前准备（开发者在仓库根目录执行一次）

```bash
# 编译前端，输出到 src/agentos/_web_assets/
make build-web

# 验证构建产物存在
ls src/agentos/_web_assets/
```

> **当前状态**：`_web_assets/` 为空，尚未构建。运行 `make build-web` 后生产模式方可使用。

### 用户安装

```bash
# 从 PyPI 安装（发布后）
pip install agentos

# 或从本地源码安装（开发阶段，在仓库根目录执行）
pip install .
```

### 创建 Agent 项目

```bash
# 新建一个工作目录
mkdir my_project
cd my_project

# 初始化 Agent 项目
agentos init my_agent
cd my_agent
```

若当前目录没有 `.env`，手动创建 `my_agent/.env`，填入 API 配置：

```
GEMINI_BASE_URL=https://your-api-endpoint/v1
GEMINI_API_KEY=你的APIKey
GEMINI_MODEL=your-model-name
```

### 启动

```bash
agentos run
# 或指定端口：
agentos run --port 8080
```

浏览器打开后端提示的地址（默认 `http://localhost:8000`）。前端由后端直接托管，**无需第二个终端，无需 Vite**。

---

## 两种模式对比

| | 开发 / 测试 | 生产 / 用户 |
|--|------------|------------|
| 启动命令 | `pnpm dev:full`（单命令）| `agentos run` |
| 终端数量 | 1 个（或 2 个分开调试）| 1 个 |
| 前端服务方式 | Vite HMR 独立进程 | 后端托管静态文件 |
| 前端地址 | `http://localhost:6493` | `http://localhost:8000`（同后端）|
| 需要前端构建 | 否 | 是（`make build-web`）|
| 前端代码修改 | 实时生效 | 需重新 `make build-web` |
| 适用场景 | 开发框架 / 调试 Skills | 普通用户使用 |

## Skills 配置参考

`agent.toml` 的 `[skills]` 段控制 Agent 可用的工具，取消注释即可启用：

```toml
[skills]
file_reader  = { source = "builtin" }   # 读取项目文件
# web_search   = { source = "builtin" }   # 网页搜索（stub）
# system_shell = { source = "builtin" }   # 执行 shell 命令（有黑名单限制）
```

### 添加自定义 Skill

在项目 `skills/` 目录新建 `.py` 文件：

```python
# skills/my_skill.py
from agentos.core.tool import tool

@tool
def my_skill(query: str) -> str:
    """工具描述，LLM 根据此描述决定何时调用"""
    return f"处理结果: {query}"
```

在 `agent.toml` 中声明：

```toml
[skills]
file_reader = { source = "builtin" }
my_skill    = { source = "local", path = "skills/my_skill.py" }
```

重启后端后生效。
